# Conteúdo do projeto

`terms.json` contém o texto aprovado dos Termos de Uso do Evidências, versão
2026-10-01, compartilhado pelo site e pela página offline da extensão.
Fonte: https://docs.google.com/document/d/1T5RMSbk5Z9V2Xj8D00EEa_ihPANZ8cy_30kg87TXjzM/edit

A captura exige consentimento e aceite explícito dessa versão. O evento local
`capture_started` registra `terms_accepted` e `terms_version` junto aos demais
dados da coleta. Mudanças no texto exigem nova versão; o aceite não persiste
entre novas capturas. Não altera os formatos assinados existentes.

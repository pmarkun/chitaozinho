Como verificar uma captura Chitãozinho

Use o validador público ou uma cópia offline do mesmo build. Os arquivos selecionados são processados no seu dispositivo e não precisam ser enviados ao servidor.

  1. Selecione o ZIP principal da captura.
  2. Adicione o arquivo .zip.sha256, se recebido.
  3. Adicione o ZIP complementar de provas, quando disponível.
  4. Confirme a chave raiz por um canal independente.
  5. Execute a validação e exporte o relatório HTML ou JSON.

Como interpretar

Hashes e assinaturas válidos confirmam que os bytes correspondem ao pacote assinado e à sequência registrada. RFC 3161 e OpenTimestamps vinculam o hash a marcos temporais externos. Recibos assinados confirmam a persistência de cada parte recebida pelo servidor.

Consulte methodology-v0.2.md para conhecer todas as camadas de garantia e a metodologia completa.

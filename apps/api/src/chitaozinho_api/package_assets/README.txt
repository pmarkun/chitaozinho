CHITAOZINHO EVIDENCE PACKAGE

This ZIP preserves the bytes, capture context, event chain, receipts and
signatures produced by Chitaozinho. It provides a traceable, independently
verifiable record and detects later changes to its signed contents.

Do not edit this archive. Verify it with the open-source Chitaozinho verifier:

1. Open the public verifier or its downloaded offline copy.
2. Select this ZIP and, when available, its .sha256 and proof bundle.
3. Confirm the trusted root-key fingerprint through an independent channel.
4. Export and preserve the verification report.

The verifier processes selected files locally. The public web version does not
upload evidence bytes.

Read methodology/methodology-v0.2.md for the methodology and
methodology/verification-guide.html for a human-readable guide. Every file is
covered by package-index.json and its server signature.
